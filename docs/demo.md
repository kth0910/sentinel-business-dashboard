# 업무관리 대시보드 시연판 실행 방법

litpage(MIT, `f55fead`)를 `app/`에 가져와 업무 화면을 붙인 시연판입니다. 서버는 TypeScript + SQLite이며, 시연 뒤 Python(FastAPI)과 PostgreSQL로 옮길 예정입니다(설계 문서 8장, 11장).

> **주의**
> - 업무관리시스템 엑셀과 데이터 폴더는 **저장소 밖**에 둡니다. `.gitignore`가 `*.xlsx`, `*.xls`, `app/data/`, `app/apps/server/data/`를 막고 있지만, 다른 경로에 두었다면 커밋하지 않도록 직접 확인하세요.
> - 계정 비밀번호를 문서나 커밋에 적지 않습니다.

## 1. 준비

- Node.js 26 이상, pnpm 10 (`npm install -g pnpm@10.32.1`)
- Windows에서는 `app/.npmrc`의 `shell-emulator=true` 덕분에 스크립트가 그대로 돕니다.

```powershell
cd app
pnpm install
```

## 2. 빌드와 실행

```powershell
cd app
pnpm build
```

PowerShell에서 환경 변수를 정하고 실행합니다. `NC_DATA_DIR`는 저장소 밖 폴더로 정합니다.

```powershell
$env:NC_DATA_DIR = 'D:\bizdash-data'
$env:PORT = '3001'
$env:NC_BOOTSTRAP_EMAIL = '<관리자 이메일>'
$env:NC_BOOTSTRAP_PASSWORD = '<관리자 비밀번호>'
$env:NC_BOOTSTRAP_NAME = '관리자'
$env:NC_BOOTSTRAP_WORKSPACE = '회사'
pnpm start
```

- 브라우저에서 `http://localhost:3001` 접속
- 처음 실행할 때 `NC_BOOTSTRAP_*` 값으로 첫 계정과 워크스페이스가 만들어집니다. 이후에는 같은 값으로 실행할 때마다 그 계정의 비밀번호만 맞춰집니다.
- 서버는 기본으로 `127.0.0.1`에서만 받습니다. 사내 다른 PC에서 접속하려면 `$env:HOST = '0.0.0.0'`을 추가하세요.
- 서버를 시작하면 기존 워크스페이스도 AI와 외부 공개가 꺼집니다(처음 한 번).

## 3. 계정 만들기

권한은 따로 두지 않습니다. 만든 계정은 모두 첫 워크스페이스의 편집자가 되고, 기본 팀(General)에 들어가 날짜별 페이지를 쓸 수 있습니다. 서버와 **같은 `NC_DATA_DIR`**로 실행합니다(서버가 켜져 있어도 됩니다).

```powershell
cd app\apps\server
$env:NC_DATA_DIR = 'D:\bizdash-data'
node --import ./src/loadEnv.ts scripts/biz-user.ts <이메일> <비밀번호> 홍길동
```

- 이미 있는 이메일이면 비밀번호만 바꿉니다.
- 로그인 화면에서 이메일 입력 → 비밀번호 입력(“Continue with a password”)

## 4. 시연 순서

1. **로그인** → 첫 화면이 **캘린더**입니다. 날짜마다 업무보고(주황 점)·매출 반영(파란 점)과 당일 증감액이 보입니다.
2. 왼쪽 **업무 › 오늘 업무보고** → 그날 업무보고가 없으면 만들어집니다. 전날 보고가 있으면 그 내용을 복사해 시작합니다.
   - 채용 현황(직군·현황·비고·지원자 수), 주요 보고(번호 목록), 일정(오전·오후)을 입력합니다.
   - 다른 브라우저 창에서 같은 페이지를 열면 동시 편집이 바로 반영됩니다.
3. 왼쪽 **업무 › 오늘 매출 현황** → 본영업 목표매출 페이지가 열립니다.
4. **엑셀 업로드** → 업무관리시스템에서 받은 엑셀(.xlsx)을 고릅니다.
   - 처음 올린 날은 **기준점**이라 변동사항이 없습니다. 시연 전날 한 번 올려 두세요.
   - 같은 날 다시 올리면 그날 결과를 다시 계산합니다(직접 바꾼 구분은 유지).
   - 매출은 확도 '확정'만, 계약일 기준으로 집계합니다. 제품명에 `(Cloud)`가 있으면 Cloud로 봅니다.
5. **변동사항** → 전날 대비 바뀐 본 영업 건이 자동 분류됩니다(목표매출 상향, 신규매출, 목표매출 제외, 확정 전환, 미분류). 구분 칸에서 바꾸면 저장됩니다. **구분 관리**에서 구분을 추가·이름 변경·삭제할 수 있습니다(삭제하면 해당 건은 미분류로).
6. **목표 설정**(매출 요약 블록 아래) → 연·분기·월 목표를 넣으면 달성률이 나옵니다.
7. **'/' 메뉴** → 아무 줄에서 `/`를 누르고 `↑`를 한 번 누르면 맨 아래 **업무** 묶음으로 갑니다. 채용 현황, 일정, 매출 요약, 변동사항, 월별 매출 차트, 진행 중 영업 건을 어느 페이지에나 넣을 수 있습니다. 매출 블록은 그 페이지의 날짜(날짜별 페이지가 아니면 오늘) 기준입니다.
8. 페이지 오른쪽 위 **•••› Version history**에서 수정 이력을 볼 수 있습니다.

시연판에서 뺀 것: AI, 자동화, 댓글, 외부 공유(웹 게시), 웹훅. 데이터베이스 보기는 표·리스트·캘린더·타임라인·차트만 추가할 수 있습니다.

## 5. 데이터 초기화

서버를 끄고 `NC_DATA_DIR` 폴더를 지운 뒤 다시 실행하면 처음 상태(첫 계정만 있는 상태)로 돌아갑니다.

```powershell
Remove-Item -Recurse -Force 'D:\bizdash-data'
```

되돌릴 수 없으니 필요하면 폴더를 먼저 복사해 두세요.

## 6. 개발 모드

```powershell
cd app
pnpm dev:server
```

```powershell
cd app
pnpm dev:web
```

- 화면 `http://localhost:5173`, 서버 `http://localhost:3001`, 데이터는 `app/apps/server/data/`(git 제외)
- 개발 모드에서는 로그인 코드가 화면에 표시됩니다.
- 단위 테스트: `pnpm --filter @nc/shared --filter @nc/server --filter @nc/web --filter @nc/biz test`

## 알려진 제한

- 로그인 화면의 Google·Apple 등 외부 로그인 버튼과 "Litpage" 이름은 litpage 원본 그대로입니다(시연판에서는 이메일+비밀번호만 사용).
- 날짜별 페이지는 워크스페이스 하나를 기준으로 기록합니다.
- 한글 입력기(IME) 조합 입력과 화면의 엑셀 파일 선택은 자동화 도구로 확인하지 못했습니다. 시연 전에 직접 한 번 확인하세요.
