### 결정 사항과 이유
- 이번에도 main에서 바로 진행(이전 계획과 같은 선택)
- 서브에이전트는 한 번에 하나만: 뒤 작업이 앞 작업 결과에 의존하고 같은 파일(`records/handlers.py`)을 고치며 같은 테스트 DB를 쓰기 때문. Task 8(화면 AI 숨기기)만 따로 돌릴 수 있었지만 사용자가 순서대로 진행을 선택
- 서브에이전트의 `git commit`은 권한 확인에서 막힘(사용자 승인 전에는 AGENTS.md 규칙 때문, 승인 후에도 막힘). 서브에이전트가 대신 커밋해 달라고 했으나 권한 우회가 될 수 있어 사용자에게 먼저 물었고, 일괄 승인 뒤로는 구현 담당은 변경만 남기고 커밋은 컨트롤러가 함
- 화면 시작 시 404가 나는 RPC 조사는 온보딩을 넘어가야 가능해서 Task 4 뒤로 미룸
- 화면↔서버는 RPC 유지: 가져온 화면 코드가 RPC 294개 이름으로 호출하고, 핵심인 `applyChanges`·`loadPage`가 자원 CRUD 모양이 아님. 외부 연동이 필요하면 REST를 따로 추가
