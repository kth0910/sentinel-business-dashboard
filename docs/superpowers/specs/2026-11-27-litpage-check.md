# litpage 0단계 검증 결과 (2026-11-27)

- 대상: `https://github.com/litmers-dev/litpage` 커밋 `f55fead`, 원본 그대로
- 실행 환경: Windows 11, Node.js 26.13.0, pnpm 10.32.1, 저장소 밖 임시 폴더
- 실행 방법: 서버(`@nc/server`, 3001)와 화면(`@nc/web`, 5173)을 따로 실행

## Windows에서 원본을 띄울 때 생긴 문제

| 문제 | 원인 | 임시 우회(원본 폴더에서만) |
|---|---|---|
| `NC_DEV_LOGIN_CODES=1 node …` 스크립트 실패 | `package.json` 스크립트의 `변수=값 명령` 형식은 Windows cmd에서 동작하지 않음 | 임시 폴더에 `.npmrc`(`shell-emulator=true`) |
| `pnpm dev` 즉시 종료(`spawn pnpm ENOENT`) | `scripts/dev.mjs`가 Windows에서 `pnpm`(`pnpm.cmd`)을 직접 실행하지 못함 | 서버와 화면을 각각 실행 |

이 저장소는 litpage 서버를 쓰지 않으므로(서버는 FastAPI) 두 문제 모두 이후 작업에는 영향이 없다. 화면(`@nc/web`) 개발 서버는 Windows에서 그대로 동작했다.

## 점검 항목

| 항목 | 통과 기준 | 결과 |
|---|---|---|
| 한국어 입력 | 문단·제목·표 셀에서 한글 조합 중 글자가 깨지거나 두 번 입력되지 않음 | 사용자 점검 완료, 문제 보고 없음 |
| 한국어 화면 | 주요 화면에 영어가 거의 남지 않음 | 사용자 점검 완료, 문제 보고 없음 |
| 데이터베이스 | 표·보드·캘린더 보기 생성, 속성 추가, 필터 동작 | 사용자 점검 완료, 문제 보고 없음 |
| 수정 이력 | 페이지 수정 후 이전 버전 열람 가능 | 사용자 점검 완료, 문제 보고 없음 |
| 모바일 폭 | 390px에서 읽기·편집 가능 | 사용자 점검 완료, 문제 보고 없음 |

사용자는 "점검 끝"이라고만 알렸고 항목별 실패를 보고하지 않았다. 항목별 세부 관찰은 기록되지 않았다.
